# ADR 004: Console platform adapter

Status: deferred, 2026-07-15.

No console target, SDK authorization, product budget, or measured console
bottleneck is in scope. A console API alone is not evidence for an adapter.

Reopening requires an approved target, owned budget, profiled default miss, SDK
licensing review, facade conformance plan, feature gate, fallback, and removal
path. The maintenance cost is per-SDK support and certification compatibility.
